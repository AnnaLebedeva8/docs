# Make changes in Visual Studio Code

1) Edit the required files locally in Visual Studio code.
2) Save the changed
3) Check the stutus of changesd files in GitHub Desktop
4) Write a description in summary to version your changes
5) Click Commit to main
6) Click Push to main 
Openn GitHub web version and proceed to Actions tab
7) Run manually commits
8) Deploy the new version of site
9) Check the changes on production
